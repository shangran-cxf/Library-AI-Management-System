# 图书管理系统作业 · 接口 curl 实测记录

> 后端：`python main.py`（http://localhost:8001）  
> 说明：以下命令与返回均为真实执行结果，用于验证任务一（续借）与任务二（评论评分）。

---

## 任务一：续借功能

### 1. 登录 zhangsan，获取 user_id

```bash
curl -X POST "http://localhost:8001/api/login" -H "Content-Type: application/json" -d '{"username":"zhangsan","password":"123456"}'
```

**响应：**

```json
{"success":true,"message":"登录成功","data":{"user_id":1,"username":"zhangsan","role":"reader","max_borrow":5}}
```

### 2. 查询 zhangsan 当前在借记录（取 record_id）

```bash
curl -X GET "http://localhost:8001/api/borrow/records/1?status=borrowing"
```

**响应：**

```json
{"code":200,"message":"查询成功","data":{"records":[{"record_id":1,"book_title":"三体","book_author":"刘慈欣","borrow_date":"2026-06-20","due_date":"2026-07-20","return_date":null,"status":"borrowing","is_overdue":false},{"record_id":2,"book_title":"深入理解计算机系统","book_author":"Randal E. Bryant","borrow_date":"2026-06-15","due_date":"2026-07-15","return_date":null,"status":"borrowing","is_overdue":false}],"total":2}}
```

### 3. 续借《三体》对应记录（record_id=1，默认延长 30 天）

```bash
curl -X POST "http://localhost:8001/api/renew" -H "Content-Type: application/json" -d '{"record_id":1}'
```

**响应：**

```json
{"code":200,"message":"续借成功！新的应还日期为 2026-08-19。","data":{"record_id":1,"book_title":"三体","old_due_date":"2026-07-20","new_due_date":"2026-08-19","extend_days":30}}
```

### 4. 再次续借同一条记录（record_id=1，显式延长 7 天）

```bash
curl -X POST "http://localhost:8001/api/renew" -H "Content-Type: application/json" -d '{"record_id":1,"extend_days":7}'
```

**响应：**

```json
{"code":200,"message":"续借成功！新的应还日期为 2026-08-26。","data":{"record_id":1,"book_title":"三体","old_due_date":"2026-08-19","new_due_date":"2026-08-26","extend_days":7}}
```

### 5. 先归还记录 2，制造'已归还'场景

```bash
curl -X POST "http://localhost:8001/api/return" -H "Content-Type: application/json" -d '{"record_id":2}'
```

**响应：**

```json
{"code":200,"message":"归还成功","data":{"book_title":"深入理解计算机系统","borrow_date":"2026-06-15","return_date":"2026-10-14","days_overdue":91,"fine":45.5}}
```

### 6. 对已归还记录续借 → 应被拒绝（业务错误）

```bash
curl -X POST "http://localhost:8001/api/renew" -H "Content-Type: application/json" -d '{"record_id":2}'
```

**响应：**

```json
{"code":400,"message":"该记录已归还，无法续借","data":null}
```

### 7. 对不存在的记录续借 → 应被拒绝（业务错误）

```bash
curl -X POST "http://localhost:8001/api/renew" -H "Content-Type: application/json" -d '{"record_id":99999}'
```

**响应：**

```json
{"code":400,"message":"借阅记录不存在","data":null}
```
