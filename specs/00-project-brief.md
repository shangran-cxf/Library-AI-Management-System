# Project Brief：图书管理系统

> 本文件是整个 Specs 的输入。人类提供项目背景与约束，Agent 据此开展后续分析。

## 1. 项目背景

本项目是《软件设计与体系结构》课程实验项目（武汉理工大学人工智能学院，2026）。
以图书管理系统为例，训练需求分析、UML 建模、架构设计、数据库设计、详细设计与代码实现能力，
并采用 **Spec-Driven（规格驱动）+ AI Agent 辅助** 的新型开发范式。

## 2. 项目目标

开发一个图书管理系统，支持：

- 读者注册账号与借阅证管理
- 图书的借阅、归还、查询
- 图书预约（网络预约）
- 系统维护（管理员、图书标题、馆藏副本、借阅规则、罚款规则）
- 超期罚款计算

## 3. 目标用户（参与者）

| 参与者 | 说明 |
|---|---|
| 读者 Reader | 抽象父类，泛指所有可以借阅的读者 |
| 学生读者 Student | 本科生 / 研究生 / 博士生 / 专科生 |
| 教师读者 Teacher | 教师 |
| 图书管理员 Librarian | 代理读者完成借书、还书、查询借阅信息 |
| 系统管理员 SystemAdmin | 负责系统维护 |

## 4. 主要业务

- 注册读者账号
- 办理 / 删除借阅证
- 借阅图书（由图书管理员代理）
- 归还图书（由图书管理员代理）
- 查询借阅信息
- 预约图书
- 维护图书标题信息
- 维护馆藏副本
- 维护图书管理员
- 维护借阅规则 / 罚款规则
- 计算超期罚款

## 5. 读者类型与借阅规则（初步）

| 读者类型 | 最大借阅数量 | 借阅期限 |
|---|---|---|
| 专科生 JUNIOR | 3 | 30 天 |
| 本科生 UNDERGRADUATE | 5 | 30 天 |
| 研究生 GRADUATE | 10 | 60 天 |
| 博士生 DOCTOR | 15 | 90 天 |
| 教师 TEACHER | 20 | 90 天 |

不同读者类型具有不同的借阅数量和期限。

## 6. 借出物类型与罚款规则（初步）

| 借出物类型 | 说明 | 超期罚金（元/天） |
|---|---|---|
| 中文图书 CHINESE_BOOK | 中文普通图书 | 0.10 |
| 外文图书 FOREIGN_BOOK | 外文原版图书 | 0.20 |
| 中文杂志 CHINESE_MAGAZINE | 中文期刊 | 0.10 |
| 外文杂志 FOREIGN_MAGAZINE | 外文期刊 | 0.20 |
| 论文 THESIS | 学位论文 | 0.50 |

不同借出物类型具有不同的超期规则和罚款规则。

## 7. 技术要求

- 使用 UML 表达分析和设计结果（用例图、类图、包图、顺序图）。
- 采用分层架构与 MVC 模式。
- 使用 Agent 辅助生成规格、UML、设计与代码。
- 所有 Agent 生成内容必须经过人工审查。
- 实现语言：**Python 3.10+ / FastAPI**（与课程作业后端一致）。
- 最终需要有可运行的代码与自动化测试。
- 全部规格以 PlantUML / Mermaid 文本格式保存到 `specs/`，纳入 Git 管理。

## 8. 暂不实现（Non-Goals）

- 支付系统真实扣款
- 图书条码扫描硬件接入
- 复杂全文检索
- 多校区馆藏调拨
- 微信 / 统一身份认证登录
- 真实短信 / 邮件通知

## 9. 关键约束

- 借书、还书必须由**图书管理员代理**完成，读者不能自行办理。
- 借书前必须验证借阅证有效性、借阅数量、是否存在超期未还。
- 还书时若超期，必须生成罚款记录。
- 借阅规则、罚款规则必须集中实现（Policy / Rule），不得散落在界面层。
