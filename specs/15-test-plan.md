# 测试计划

> 来源：`02-requirements.md`、`03-use-cases.md`、`09-design-model.md`、`14-api-spec.md`。
> 测试框架：pytest + httpx。测试类型分为 **单元测试（U）**（直接调用领域策略 / 服务）与 **集成测试（I）**（通过 FastAPI TestClient 调用接口）。

## 1. 测试策略

| 层级 | 类型 | 说明 |
|---|---|---|
| 领域策略 | 单元测试 | `BorrowPolicyService`、`FineRuleService` 规则正确性 |
| 应用服务 | 集成测试 | 通过 API 调用，覆盖借书 / 还书 / 预约 / 查询 / 权限 |
| 表现层 | 集成测试 | 统一响应结构、错误码 |

测试数据准备：`conftest.py` 提供内存 SQLite fixture 与 TestClient，预置读者、借阅证、管理员、图书标题与副本种子数据。

---

## 2. 测试用例

| 项 | 内容 |
|---|---|
| 测试目标 | 读者可通过接口注册账号 |
| 前置条件 | 账号未被占用 |
| 输入 | `POST /api/readers`：`{name, department, reader_type:"UNDERGRADUATE", account, password}` |
| 操作步骤 | 1. 调用注册接口 2. 读取返回 `reader_id` |

